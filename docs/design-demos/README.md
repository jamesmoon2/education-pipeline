# Design demos

Standalone visual studies for the proposed Education Pipeline design system.
They do not depend on the React application, provider daemon, remote fonts, or
network assets.

Open [`index.html`](index.html) in a browser, or serve this directory with any
local static server. The demos include:

- `new-course.html` — guided course setup;
- `workbench.html` — course-production run and evidence rail; and
- `guide.html` — learner-facing interactive guide section; and
- `pipeline-value.svg` — animated value proposition and pipeline walkthrough.

These are design prototypes, not production components. Interaction is deliberately
limited to theme switching, outline approval, guide navigation, a knowledge check,
and section completion.
