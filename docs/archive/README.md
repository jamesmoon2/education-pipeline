# Archived planning documents

These documents record earlier stages of the Education Pipeline extraction and
cockpit build. They are retained for historical context and implementation
provenance, but they no longer define current product requirements.

The authoritative product direction is
[`../product-requirements.md`](../product-requirements.md).

- `roadmap.md` — initial package and pipeline roadmap.
- `open-source-readiness-plan.md` — original public-extraction and productization
  plan, including assumptions inherited from the private source project.
- `frontendplan.md` — three-phase cockpit roadmap, archived after all phases
  merged.
